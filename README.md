## 🔧 What I Do
- 🧠 **AI Memory Infrastructure**: Created **PowerMem**, an open-source intelligent memory system for AI agents that supports hybrid retrieval (vector + full-text + graph), user profiling, and Ebbinghaus forgetting-curve–based decay—while maintaining **API compatibility with Mem0** to ease adoption in existing agent ecosystems .
- 🤖 **AI4DB Research**: Advancing autonomous database systems through learning-based approaches—applying machine learning and reinforcement learning to intelligent knob tuning, query optimization, anomaly detection, and self-healing diagnostics.
- 🕵️‍♂️ **Diagnose OceanBase**: Building intelligent diagnostic tooling for large-scale deployments  
- 🔌 **Ecosystem Integration**: Bridging OceanBase with modern DevOps & observability stacks  
- 📣 **Tech Advocacy**: Sharing best practices, writing docs, speaking at meetups & conferences  
- 🤝 **Community Leadership**: As a TOC member, helping shape the future of the OceanBase open-source project
